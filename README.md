# 清明 · 虹桥

《清明上河图》交互式网页：滚轮横展长卷（春郊 → 汴城 → 虹桥），虹桥之下悬一幅清明诗句织成的物理布帘，鼠标拂过或拖动诗帘，铜钟应声而起。

- 访问：`https://nexsjournal.github.io/qmsht-poetry-web/`
- 文档：[开发文档](docs/开发文档.md) · [设计文档](docs/设计文档.md) · [技术栈](docs/技术栈.md) · [功能文档：过桥行人](docs/过桥行人功能文档.md)
- 致谢：交互形式 Marina Budarina「chimes」；布帘物理 Liam Egan（CodePen）；画卷《清明上河图》张择端（公有领域）
