# 技术栈

| 类别 | 选型 | 说明 |
| --- | --- | --- |
| 结构 | 原生 HTML5 | 单页 `index.html`，无模板引擎 |
| 样式 | 原生 CSS3 | 单文件 `css/style.css`，无预处理器 |
| 逻辑 | 原生 JavaScript（ES2022，ES Module） | 无框架、无构建步骤，浏览器直接运行 |
| 渲染 | Canvas 2D | 字符预渲染为离屏纹理，逐帧 `drawImage`，支持 DPR 缩放 |
| 物理 | Verlet 积分 + 距离约束 | 移植自 Liam Egan 的 string physics（CodePen），即参考站 chimes 同款布帘引擎 |
| 音频 | Web Audio API | 振荡器 + 非谐部分 + 带通噪声合成铜钟声，零音频文件、零外部请求 |
| 字体 | Google Fonts | Noto Serif SC（正文/诗帘，宋体）、ZCOOL XiaoWei（展示标题）、JetBrains Mono（面板数字） |
| 部署 | GitHub Pages | 纯静态，`gh` CLI 建库 + 开启 Pages，无 CI |
| 素材处理 | Pillow（本地一次性脚本） | 长卷降采样为 Web 尺寸、虹桥裁切为横带，均已入库，运行时不再处理 |

**刻意不用的东西**：构建工具（Vite/Webpack）、框架（React/Vue）、物理引擎库（Matter.js——自研 Verlet 更轻且行为可控）、音频文件（合成音体积小、可调参、无版权风险）、Tweakpane（参考站用它做面板，本项目自绘面板以完全贴合视觉并去掉外部 CDN 依赖）。

**外部依赖仅一项**：Google Fonts（含失败回退：本地宋体字族 `Songti SC / STSong / SimSun`）。
