# 《清明 · 虹桥》设计文档

## 1. 设计定位
一幅可以“展开”的清明上河图：绢本设色的底色 + 宋体诗帘 + 铜钟声。整体气质——**古画为底、诗为帘、声为风**。
形式参考 Marina Budarina《chimes》：中央建筑 + 悬挂文字布帘 + 右上角参数面板 + 底部大字文案。

## 2. 视觉风格
- **底色**：直接使用《清明上河图》原卷（qmsht-web.jpg）作全屏背景，不做额外纹理；默认 `opacity: 0.16` 近乎透明，化作绢底水印，主角留给虹桥与诗帘；绢底为暖纸色渐变（#e9dcc2 → #ddc9a4）。
- **展画卷模式**：右下角「展画卷」按钮，点击后虹桥、诗帘与底部文案整体淡出收起，画卷恢复全幅（opacity 1）供专注浏览，按钮变「回诗帘」；再点恢复。进度条（郊野/汴城/虹桥）在两种模式下均保留。
- **桥**：虹桥效果图（hongqiao-web.png）悬浮于画卷之上，底部水线已柔化，叠一层椭圆软阴影与画卷融合。
- **诗帘**：墨色（#241f18）宋体小字密排成帘，远看是织物质感，近看是诗——与参考站“字密成帘”的处理一致。
- **UI 色板**（取自参考站绢面 + 画卷土色）：

| 用途 | 色值 |
| --- | --- |
| 面板底 | #f6efe3 → #efe6d5 |
| 深棕（按钮/表头/滑杆头） | #4a3a33 |
| 绢面浅棕（分隔/文件夹头） | #eadfca |
| 描线 | #d8c9b0 |
| 墨色文字 | #2a2620 |
| 说明灰棕 | #6b5847 |

- **字体**：
  - Noto Serif SC 400/600/900 —— 正文、诗帘、面板（宋体，Google Fonts）
  - ZCOOL XiaoWei —— 品牌、大标题（带宋刻意趣的展示体）
  - JetBrains Mono —— 面板数字、进度刻度
  - 回退链：`"Songti SC","STSong","SimSun",serif`

## 4. 内容设计

### 4.1 清明诗库（帘上文字）
选诗标准（按相关度分级，均已收录，公有领域文本）：
- **T1 清明/寒食直接相关**（节日本题）：杜牧《清明》、韩翃《寒食》、白居易《寒食野望吟》、苏轼《寒食雨二首》（节选）、高翥《清明日对酒》、王十朋《清明》
- **T2 踏青·寻春·春雨**（清明习俗与气候意象）：朱熹《春日》、欧阳修《清平乐·春归何处》、辛弃疾《摸鱼儿》（节选）、李清照《如梦令》、韦庄《思帝乡》、孟浩然《春晓》、杜甫《春夜喜雨》、高鼎《村居》、杨万里《宿新市徐公店》、杜甫《绝句》（两个黄鹂）、叶绍翁《游园不值》
- **T3 春江·烟柳**（与画卷汴河、柳岸、市井烟火相呼应）：苏轼《惠崇春江晚景》、白居易《钱塘湖春行》、杜牧《江南春》、刘禹锡《竹枝词》、陆游《游山西村》、王维《田园乐》、杜甫《江畔独步寻花》、张若虚《春江花月夜》（节选）、张志和《渔歌子》、龚自珍《己亥杂诗》、范成大《四时田园杂兴》、苏轼《饮湖上初晴后雨》、杜甫《绝句》（迟日江山丽）、王维《送别》、袁枚《所见》

> 说明：本环境无法直连搜索引擎，选目按公认选本（清明诗词类选目）从经典篇目中核定，均为流传最广、与“清明”相关度最高者；长句一律取完整原句，不拼接、不改字。

## 5. 动效与声音设计
- **布帘默认手感**：重力 0.2 / 阻尼 0.99 / 拉伸 1.5 —— 落下即止，轻触微波，重挥大幅，与参考站一致。
- **钟声**：青铜钟音色（偏磬），五声 C-D-E-G-A 两列八音；悬停=轻叩（强度随距离），抓取=重击；音高随列位置，横移鼠标如弹筝。
- **展卷**：滚轮驱动 t 值，指数缓动跟随；进度条三段标注 郊野/汴城/虹桥（虹桥在画卷左端，即滚动终点——“一路展到虹桥”的叙事）。
- **入场**：布帘生成后先预松弛若干帧再上屏，避免首帧塌落动画突兀（参考站同款处理）。
- **无障碍**：`prefers-reduced-motion` 时关闭背景缓动（改为瞬时跟随）；交互元素均有 `aria` 标注；全键盘可达面板。
