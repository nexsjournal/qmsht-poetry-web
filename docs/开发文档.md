# 《清明 · 虹桥》开发文档

交互式网页：以《清明上河图》长卷为横展背景，画面中央为虹桥，桥下悬一幅由清明诗句织成的物理布帘；滚轮横展画卷，鼠标拂过/拖动诗帘触发合成钟声。交互形式与视觉风格参考 marinabudarina.github.io/chimes。

## 1. 目标与验收

## 3. 模块说明

### 3.1 布帘物理（main.js）
移植参考站（其物理源自 Liam Egan CodePen）：
- 粒子：`gridW × gridH` 个，首行（j=0）固定（钉在桥下）。
- 约束：竖向结构约束（全强度）+ 横向弱约束（compress 0.6 / stretch 4，仅作列间距参考）。
- 积分：Verlet，`velocity = (pos - oldPos) * damping`，重力按 `gravity / dt²` 施加；每帧 `iterations`（精度）次约束松弛。
- 渲染：每个粒子取一个字（`charForCell`），字符预渲染到离屏 canvas（含 DPR），绘制时沿下方约束方向旋转，使字随布帘倾斜。
- 交互：`pointerdown` 抓最近的粒（半径 24px，强敲击出声）；`pointermove` 对 `mouseSize` 半径内粒子施加径向力（`smoothstep(mouseSize,-2000,ls)*strength/300`），并对 55px 内最近粒子触发钟声。
- 重建：尺寸/列/行/篇目变化时 `rerender()`（解绑输入、取消 rAF、重建粒子与约束）。

### 3.2 取字（utils.charForCell）
竖排右起：`index = (gridW-1-i) * gridH + j`，越界取模循环（参考站同款）。诗库长度 ≈1400 字，36×40=1440 格，末列循环回卷不可见级别。

### 3.3 背景横展（main.js）
- 长卷按 100vh 等高铺满，`translateX = -(1-t) * (imgW - vw)`，`t∈[0,1]`，`t=0` 为最右端（长卷传统起幅：春郊）。
- 「展画卷」模式（`body[data-mode=painting]`）：画卷 `opacity` 0.16→1（0.9s 过渡），`.area`（虹桥+诗帘）与底部文案淡出上移并锁定输入（布帘物理仍后台运行，恢复无跳变）；「回诗帘」还原。
- 滚轮：`t += deltaY * 0.00045`（deltaMode 归一化），rAF 指数缓动 `k = 1 - exp(-3dt)`。
- 触屏：水平拖动直接映射 `t`。
- 底部进度条三段标注：郊野(0) — 汴城(0.5) — 虹桥(1)，对应手卷三段式构图（虹桥位于画卷左端）。

### 3.4 音频（chimes.js）
- 首次用户手势后 `AudioContext.resume()`（浏览器自动播放策略）。
- 音色：青铜钟——五声频率 `[C4 D4 E4 G4 A4 C5 D5 E5]`，部分谐波 `[1.0,1.5,2.0,2.76,4.07]`，频率下垂 0.988，带通打击噪声；音长 1.45s。
- 触发：悬停（intensity 0.2–0.9 随距离）、抓取（强制，intensity 0.85）；节流 60ms，同粒去重，最多 10 声叠加。
- 音高映射：`列号/(gridW-1)` → 音阶下标（从左到右 C→E，横移即“弹奏”）。

### 3.5 控制面板（panel.js，自绘）
结构：标题栏（可折叠）+ 三个文件夹（篇目 / 布帘 / 动效与声音），样式仿参考站（米褐底、深棕方块滑杆头、Mono 数字框）。
- 篇目 select：`全卷·清明诗选 / 清明·寒食 / 踏青·寻春 / 春江·烟柳`，切换即重建布帘。
- 布帘：宽 100–800 / 高 80–700 / 列 2–200 / 行 2–100，`change` 时重建；「重建布帘」按钮强制重建。
- 动效与声音：滑杆实时生效；拉伸/压缩直接改写现有约束的 min/max 长度（参考站同款事件通道）；风铃=总静音开关；音量 0–1。
- 默认值（对齐参考站截图）：564 / 228 / 36 / 40 / 0.20 / 0.990 / 5 / 1.50 / 0.02 / 5000 / 4 / 开 / 0.28 / 关。

## 6. 风险与对策
- **音频自动播放**：需首次点击/滚轮等手势后出声；Play 语义改为「音律」按钮打开面板，声音随交互自然启动。
- **大纹理**：长卷已降采样；若低端设备仍卡，可后续切分为 2–3 段横带按需加载（预留 `qmsht-web-*` 命名）。
- **字体未就绪**：`document.fonts.load()` 完成后再构建布帘，避免 Canvas 用回退字体烘焙字符。
- **移动端**：触屏横拖展卷 + 触摸拖动布帘；面板收窄为 90vw；不追求与桌面一致的手感。
